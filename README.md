# AyED Exams Repository

Curated repository of Algorithms and Data Structures (AyED) exams and make-up exams used in university-level teaching contexts.

## Purpose

This repository centralizes exam statements and reference solutions that were originally distributed across multiple course repositories.

## Structure

- `01-parcial-2024-06-29-sabado-com5/`
  - Topics: binary file processing, priority queue/list management, disk access scheduling
- `02-parcial-2024-comision7-viernes/`
  - Topics: OOP modeling, linear search, sorting algorithms, linked lists
- `03-recuperatorio-2024-07-03-miercoles/`
  - Topics: OOP, binary search, linked lists, iterators, persistence with `pickle`

Each folder includes:

- `README.md`: English teaching guide with objectives, topic tags, and grading rubric
- `README.original.md`: original exam statement as published
- `ejercicio*.py`: practical exercise files and/or reference implementations
- supporting assets if required (images, etc.)

## Notes

- This material is intended for educational and academic use.
- Original context and wording are preserved in each `README.original.md`.
- Folder names were standardized for consistency and easier navigation.
