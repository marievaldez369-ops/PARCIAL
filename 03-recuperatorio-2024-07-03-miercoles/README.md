# Make-up Exam - AyED (Wednesday)

## Overview

This make-up exam combines object-oriented design, search algorithms, linked lists, iterators, and persistence.

- Format: Individual attempt
- Time limit: 4 hours
- Delivery model: GitHub Classroom
- Original statement: see README.original.md

## Learning Objectives

- Extend class models incrementally while preserving previous behavior.
- Implement binary search in practical domain scenarios.
- Build linked-list structures and iterator-based traversal.
- Persist and restore data using serialization tools.
